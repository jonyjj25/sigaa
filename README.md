# SIGAA

Sistema Integral de Gestion Administrativa y Asistencia.

SIGAA es un sistema de gestion institucional pensado para operar en web y movil. El proyecto esta dividido en frontend y backend para facilitar el desarrollo, mantenimiento y despliegue.

## Estructura del proyecto

```text
SIGAA/
├── backend/
│   └── sigaa-api/        # API REST con Spring Boot
├── frontend/             # Aplicacion Ionic / Angular
├── database/             # Scripts y notas de base de datos
└── docs/                 # Documentacion tecnica y de instalacion
